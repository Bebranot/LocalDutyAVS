# Fury-16 — музыка стадий

Сюда положи реальные треки и пропиши пути в `FuryStimulatorComponent`
(`MusicIntro` / `MusicPeak` / `MusicDecline`) вместо временных заглушек:

- **PATH_SOUND_1** (`MusicIntro`) — «разогрев», стадии ввода (45–50) и выхода (0–5).
- **PATH_SOUND_2** (`MusicPeak`)  — пик действия (25–45).
- **PATH_SOUND_3** (`MusicDecline`) — спад (5–25).

Треки зациклены и играют персонально для игрока с плавным crossfade между стадиями,
поэтому лучше подходят closed-loop композиции без резкого «хвоста».

Пока по умолчанию подставлены существующие треки проекта (см. TODO в компоненте).
